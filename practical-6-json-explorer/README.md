# Practical 6 - Campus Data Explorer

A simple HTML, CSS, and JavaScript project for working with JSON files using the Fetch API.

## Contents
- `index.html` — page structure and controls
- `css/style.css` — simple responsive layout
- `js/app.js` — UI state, search, filter, sorting, pagination
- `js/data.js` — Fetch API and JSON parsing
- `js/render.js` — reusable record-card rendering
- `data/events.json` — 15 event records
- `data/students.json` — 15 student records
- `data/faqs.json` — 15 FAQ records
- `PRACTICAL-6-REPORT-NOTES.md` — analysis answers and test checklist

## Run
Open the folder in VS Code and start Live Server. Fetching local JSON may fail if you open the page directly with a `file://` URL.

## Features
Search, category/course/topic filters, alphabetical and date/year sorting, six-record pagination, and loading/empty/error states.

The JSON records are sample data; the project does not send information to a server.
